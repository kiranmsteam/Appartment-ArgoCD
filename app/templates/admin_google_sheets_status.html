Quick-start: Step 5 – How to set these variables

The easiest method is to edit the startup script you already use to launch the app:

Windows – start.bat

  1. Right-click start.bat → Edit (opens in Notepad).
  2. Find the block that starts with REM set GOOGLE_SHEETS_CREDENTIALS_FILE=PASTE_…
  3. Remove REM  from the beginning of each of the five lines.
  4. Replace the PASTE_… placeholder on each line with your real value.
  5. Save the file, then double-click start.bat to launch the app.

Windows – start.ps1

  1. Open start.ps1 in Notepad or VS Code.
  2. Find the five lines starting with # $env:GOOGLE_…
  3. Remove the #  from the start of each line.
  4. Replace the PASTE_… placeholder on each line with your real value.
  5. Save and run the script.

Linux / macOS – start.sh

  1. Open start.sh in a text editor.
  2. Find the five lines starting with # export GOOGLE_…
  3. Remove the #  from the start of each line.
  4. Replace the PASTE_… placeholder on each line with your real value.
  5. Run bash start.sh.

How to find your Spreadsheet ID

Open each Google Sheet in your browser. The URL looks like:

https://docs.google.com/spreadsheets/d/1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgVE2upms/edit

The bold part between /d/ and /edit is the Spreadsheet ID. Copy it for each sheet.

Full setup guide

The complete step-by-step guide (Steps 1–7) is in GOOGLE_SETUP.md in the repository.

  1. Create a Google Cloud Project and enable the Google Sheets API and Google Drive API.
  2. Create a Service Account and download its JSON key file.
  3. Upload your three Excel files to Google Drive and convert them to Google Sheets.
  4. Create a blank Google Sheet for user credentials and share it with the service account (Step 5U in GOOGLE_SETUP.md).
  5. Share the financial spreadsheets with the service account e-mail (set role to Editor).
  6. Set the five environment variables above (see instructions above).
  7. Install dependencies: pip install -r requirements.txt
  8. Restart the app and come back to this page — it should show Connected and all diagnostics green.
